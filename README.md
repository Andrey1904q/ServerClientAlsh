# SocketApp — Клиент-серверное приложение на WinSock2

Консольное клиент-серверное приложение на C++ под Windows.  
Реализует обмен текстовыми сообщениями между сервером и клиентом через TCP-сокеты (WinSock2).

---

## Структура проекта

```
SocketApp/          <- Solution
├── Server/         <- Project: сервер
│   └── server.cpp
└── Client/         <- Project: клиент
    └── client.cpp
```

---

## Используемые функции WinSock2

| Функция | Описание |
|---|---|
| `WSAStartup` | Инициализация библиотеки WinSock |
| `socket` | Создание сокета |
| `bind` | Привязка сокета к IP-адресу и порту |
| `listen` | Перевод сокета в режим прослушивания |
| `accept` | Принятие входящего подключения от клиента |
| `connect` | Подключение клиента к серверу |
| `send` | Отправка данных через сокет |
| `recv` | Получение данных через сокет |
| `shutdown` | Завершение приёма/передачи данных |
| `closesocket` | Закрытие сокета |
| `WSACleanup` | Освобождение ресурсов WinSock |

## Настройка проекта в Visual Studio

### 1. Создать Solution с двумя проектами

**Создаём проект Server:**
- Файл → Создать → Проект
- Тип: Консольное приложение (C++)
- Имя проекта: `Server`
- Имя решения: `SocketApp`

**Добавляем проект Client:**
- В Solution Explorer → правая кнопка на Solution → Добавить → Новый проект
- Тип: Консольное приложение (C++)
- Имя проекта: `Client`

### 2. Вставить код

- В `Server` → заменить содержимое `.cpp` файла на `server.cpp`
- В `Client` → заменить содержимое `.cpp` файла на `client.cpp`

### 3. Настроить выходные папки (оба .exe должны быть в одной папке)

Для каждого проекта:
- Правая кнопка на проекте → Свойства
- Свойства конфигурации → Общие
- Выходной каталог → установить:
  ```
  $(SolutionDir)$(Platform)\$(Configuration)\
  ```
- Применить для обоих проектов

### 4. Собрать решение

- Сборка → Собрать решение (`Ctrl+Shift+B`)
- Убедиться: 0 ошибок в обоих проектах

## Запуск

> **Важно:** сначала запускается сервер, потом клиент.

### Способ 1 — через Проводник
1. Перейти в папку `SocketApp\x64\Debug\`
2. Запустить `Server.exe`
3. В меню сервера выбрать `1. Запустить сервер`
4. Запустить `Client.exe`
5. В меню клиента выбрать `1. Подключиться к серверу`

### Способ 2 — через Visual Studio
1. Правая кнопка на Solution → Свойства
2. Общие свойства → Запускаемый проект → Несколько запускаемых проектов
3. `Server` — действие: **Запуск**
4. `Client` — действие: **Запуск**
5. `Server` должен быть выше `Client` в списке (стрелками)
6. Нажать OK → запустить `F5`
